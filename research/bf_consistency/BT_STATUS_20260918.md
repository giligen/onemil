## 7. Open items this run surfaced

1. **The resim path is not exit-faithful (−$10.3K / 7.4%).** Two concrete gaps: the
   exhaustion rule does not re-fire, and `post_fill_exit` is not modeled. Either fix
   `--resim-exits` to reproduce them, or stop quoting resim levels entirely and quote
   only resim *deltas*. Every P1 number in CLAUDE.md and README §5/§6 is a resim level.
2. **regen-8 will not fix item 1** — the drift is in matched rows. regen-8 is still
   worth running (it closes the $1,337 entry residual and would produce a faithful
   partial book in one pass), but it should not be sold as the fix for the exit gap.
3. **Quote the consistency bar at the live rail.** P1's worst month is −$7.6K at −2.5u
   and −$12.7K at the live −5u. The bar and the evidence must use the same rail.
4. **CLAUDE.md wording**: "no existing cache can be re-simulated exactly" → the entry
   level *can* be recovered for 93% of rows via `--resim-rich`; the exits cannot.
