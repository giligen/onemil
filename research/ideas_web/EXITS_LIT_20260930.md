# Literature + practitioner review — mid-flight EXIT / trade-management rules for intraday breakout longs (2026-09-30)

Owner ask: "do more literature reviews, and check all those amateur YouTube 'experts'" for exit/trade-management
ideas. Read-only WebSearch/WebFetch, 45-call budget. Cross-referenced against the 35 hypotheses (H1-H35, families
F1-F7) in `research/hod_entry/PREREG_1681.md`. No number here is a result — this is an idea inventory only; every
"new" rule still needs its own PREREG, obtainability check, and independent rebuild before it touches a book.

Evidence quality: **A** = academic, peer-reviewed or arXiv with real OOS/theory; **B** = backtest shown (quant blog,
informal repo, non-peer-reviewed paper) with a stated method; **C** = practitioner anecdote/interview/blog, no
backtest shown.

## Ranked shortlist — NEW rules only (≤20), ordered by (evidence quality, feasibility)

1. **E1** (A, high) — gate every stop/target rule on a serial-correlation test of the post-entry path first (Kaminski & Lo).
2. **E12** (A, high) — require ≥2-of-{engulf, lower-high, wick, volume} co-firing before any candle-shape exit counts (refutes lone-candle OOS power).
3. **E13** (A, high) — wall-clock session de-risk gate (tighten/exit into the ~12:30-13:30 ET doldrums) distinct from elapsed-time-since-entry.
4. **E10** (A, medium) — gate WHICH exit mechanism (fixed vs vol-adaptive) on the day's realized-vol regime.
5. **E14** (A, medium) — derive target/stop analytically from the trade's estimated process parameters instead of a fixed R; check if H18-H28's levels are too tight.
6. **E7** (A/B, medium) — online Beta-Binomial update of book win-rate; de-risk new entries when the implied Kelly fraction goes ≤0.
7. **E3** (A, low) — jointly solve stop level + size from first-passage density (heavier lift, flag for later).
8. **E4** (B, high) — Chandelier trail: N-bar high − k×ATR, as a third trail anchor alongside H27/H28.
9. **E8** (B, high) — MAE-percentile ceiling exit using the MAE/MFE columns already in `1670_per_fill_k.csv` — cheapest new idea to test, zero new data.
10. **E15** (B, high) — 75%-out-at-+1R (thin runner) as a new H18/H22 fraction variant.
11. **E2** (B, medium) — book-level drawdown-from-peak circuit breaker (momentum-crash literature).
12. **E11** (B, medium) — day-level calm/turbulent vol-regime exposure gate.
13. **E18** (C, high) — require ≥2-of-3 {EMA break, lower highs, blow-off wick} before a "change in character" exit.
14. **E20** (C, high) — EMA-band ("Bone Zone") trail: stop below the most recent swing low while price stays inside the 9/20-EMA band.
15. **E29** (C, high) — buffer the breakeven stop by ~0.1-0.3 ATR instead of placing it at literal entry (stop-hunt-wick protection).
16. **E16** (C, high) — unequal 3-tranche scale-out (half, then a quarter of the remainder, discretionary runner).
17. **E28** (C, high) — first-red-candle-at-fine-timeframe exit, gated on prior partial + breakeven stop already set.
18. **E21** (C, high) — volume-dry-up measured relative to the recent extension, not the original break bar.
19. **E25** (C, high) — volume-below-breakout-bar fade signal (vs H29's last-5-bar-mean definition).
20. **E5** (C, high) — Parabolic-SAR trail gated by an ADX trend filter to suppress chop whipsaw.
